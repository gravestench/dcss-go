# Okawaru Active Abilities Design

## Intent

Complete Okawaru's three active powers as one patron domain. The goal is
faithful play and a readable, modifiable Lua implementation: invoking a
power, its continuing effects, Arena travel, and save/restore must all use
the same state. The pinned reference is `crawl-ref/source` at `e60ba356`.
This design follows the previously approved Lua policy, ECS ownership,
committed content, and whole-domain slice decisions.

## Source contract

The source grants Heroism at one star, Finesse at four, and Duel at five.
Their ability table gives MP costs 2, 5, and 7; ordinary piety bases 1, 3,
and 10; and Invocations failure tuples `(30,6,20)`, `(60,4,25)`, and
`(80,4,20)`. A failed invocation spends a turn without paying the success
cost. Penance and departure remove active Heroism and Finesse.

Heroism adds five effective levels, capped at 27, to source mundane skills
through Unarmed Combat. It neither changes earned skill points nor adds to
magic skills. Finesse halves melee and ranged attack delay using source
rounding, without compounding with Haste. Entering Berserk cancels Finesse.
Both effects extend by `10 + random2avg(skill(SK_INVOCATIONS, 6), 2)` turns,
with a 100-turn cap. They tick in elapsed aut and retain their timers in the
player ECS state across saves.

Duel needs a visible, eligible, hostile, tough monster. Firewood, conjured
monsters, tentacles, water or lava natives, nonhostile actors, and ordinary
summons are invalid. A qualifying illusion reveals itself and spends a turn
without opening Arena; after a successful failure check, it pays the same
7 MP and rolled piety as a completed challenge. A successful challenge
alerts the target, breaks constriction, discards its carried inventory,
stops the player's delay, and moves both actors to Arena. The source Arena
branch has one level, despite having no natural entrance depth. Its four
committed `.des` maps are selected through the normal mod VFS. The chosen
map's entrance, target marker, terrain, spectators, no-item rule, and
no-teleport/no-monster masks are live rules. Killing the final current duel
target opens the exit; a Bennu revival or slime split carries the duel
identity forward, while an ordinary clone does not. Leaving while a target
lives returns it adjacent to the player and discards its inventory again.
Victory and abandoned-duel state are saved and drive the timed return.
Renunciation ends an active Duel and
returns its target; penance removes Heroism and Finesse while leaving a
valid Arena visit intact.

## Ownership and flow

- `policy/abilities/okawaru/*.lua` owns live rank gates, preparation,
  failure, and payment. This slice adds the three source IDs to the shared
  Lua ID module; the Go ability bridge has no Okawaru-specific switch.
- `policy/religion/okawaru/status.lua` owns Heroism and Finesse timers. The
  player has one saved component with independent durations. Combat skill
  readers and attack-delay policy consult this owner. A Lua system ticks
  both fields; the save validator checks the same component.
- `policy/world/arena/*.lua` owns Arena layout choice, transit, victory,
  exit, and return. Four individually named `.des` maps retain the source
  MAP rows. Named Lua hooks implement their source script behavior, while
  source script text remains explained in comments as the current DES hook
  policy requires. A saved player visit component contains origin, arena
  level, and result. Current duel targets carry a separate ECS component;
  split/revival transfers it, clone creation clears it, and the
  existing death event asks whether any current target remains. Dense
  terrain stays in the region grid.
- The generic Lua portal transaction and movement APIs stage the complete
  Arena state before applying it. Failed validation or generation leaves
  the original floor, monsters, MP, and piety untouched.
- This slice adds Arena entry/exit features to the Lua terrain vocabulary
  and lets the existing stair command recognize its exit through a Lua
  travel policy. The source Arena has no ordinary branch stair link and is
  never generated by normal Dungeon progression.

## Alternatives considered

Hardcoding an Arena grid in Go would be shorter initially but would break
the project's source-map and layered-mod contract. Reusing a Gauntlet
portal object would add a physical gate that Duel does not have. A Lua
Arena owner using the shared DES catalog and region transition APIs keeps
authored content replaceable and state changes local to the patron domain.

## Verification

Lua `_test.lua` files exercise rank gates, MP and piety, failure, duration
refresh and expiry, skill caps, Finesse timing and Berserk cancellation,
Duel eligibility, all four maps, victory exit, abandonment, and malformed
saved state. Game tests command the powers through the normal bridge, save
during an active duel, restore, kill or leave the target, and verify the
return floor. Terminal tests check menu and Arena rendering where feasible.
Text snapshots show each Arena layout and its entry/exit connection.

The whole category lands in one commit on `main` and is pushed to the fork.
Its inventory entry states the exact playable contract and any remaining
source discrepancies discovered during implementation.
